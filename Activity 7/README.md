
# Activity 7: AI-Generated Resume Comparison

## Description
This activity focused on using two different AI tools to generate a professional resume using the same information. The outputs were compared based on their design, content, organization, and overall presentation to determine which resume was more suitable.

## What I Have Learned
- Learned how AI tools can help create and organize a professional resume.
- Understood that different AI tools can produce different results.
- Improved my ability to compare and evaluate AI-generated outputs.
- Learned the importance of reviewing and double-checking information generated by AI.
